# Cyber Sathi - Your Digital Safety Companion

**Think Before You Click. Check. Understand. Stay Safe.**

Cyber Sathi is a modern cybersecurity platform designed to help ordinary users identify and understand potential online threats. It provides tools to analyze suspicious URLs, QR codes, screenshots, and messages to help protect against scams, phishing, and other digital threats.

## 🌟 Features

- **URL Scanner**: Analyze suspicious website URLs for security risks
- **QR Code Scanner**: Upload or scan QR codes to reveal hidden destinations
- **Screenshot Analyzer**: Detect warning signs in payment screens, messages, and offers
- **Message Checker**: Analyze SMS, email, and chat messages for scam indicators
- **Online Store Checker**: Evaluate shopping websites for potential fraud
- **Phishing Education**: Interactive examples to learn about phishing attacks
- **Scam Library**: Comprehensive database of common scam types
- **Emergency Guide**: Immediate steps if you've been targeted by a scam

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No backend or server required
- No dependencies to install

### Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/cyber-sathi.git
cd cyber-sathi
```

2. Open `index.html` in your web browser

That's it! The platform is entirely self-contained and runs directly in your browser.

### GitHub Pages Deployment

To deploy to GitHub Pages:

1. Push the repository to GitHub
2. Go to repository Settings > Pages
3. Select the main branch as the source
4. Your site will be available at `https://yourusername.github.io/cyber-sathi`

## 🎯 Core Functionality

### URL Scanner

The URL scanner analyzes websites for:
- HTTPS encryption status
- Domain structure and patterns
- Suspicious keywords and patterns
- IP-based URLs
- Punycode domains
- Excessive subdomains
- Suspicious ports

### QR Code Scanner

The QR scanner provides:
- Image upload for QR code analysis
- Camera scanning support (where available)
- Destination URL analysis
- Automatic security checks on decoded URLs

### Screenshot Analyzer

The screenshot analyzer detects:
- Urgency indicators (act now, immediate action)
- Financial requests (send money, pay fee)
- Credential requests (password, OTP, PIN)
- Phishing indicators (fake verification, login requests)
- Offer scams (unrealistic discounts, guaranteed profits)

### Message Checker

The message checker identifies:
- Urgency and threats
- Financial requests
- OTP and password requests
- Suspicious links
- Fake prizes and offers
- Job and investment scams
- Impersonation language

## 🔒 Privacy & Security

Cyber Sathi is designed with privacy in mind:

- **Local Processing**: Analysis happens in your browser when possible
- **No Data Storage**: We don't permanently store your data
- **No Credential Collection**: We never ask for passwords, OTPs, or banking details
- **No Automatic Uploads**: Screenshots are only analyzed when you choose to upload them
- **Open Source**: Full transparency in our code
